# reproduction package for Restraining Epidemic Resurgence through Regulating Higher-Order Contact Networks in the United States

This repository contains the experiment code and Bash workflows for the formal
experiments, the Fig. 4h and Fig. 5 main-result plots, and the toy-model
experiment. The plot-ready experiment outputs are not stored in this Git
repository; they are provided in the Zenodo reproduction archive.

## Contents

- `us_reopen/`: formal county-level experiment Python package.
- `ODtoy/`: toy-model Python code.
- `bash/run_formal_experiments.sh`: complete formal curve and repeated-run entry.
- `bash/run_toy_model.sh`: toy-model entry.
- `bash/plot_toy_outputs.sh`: replot entry for the bundled toy-model results.
- `bash/plot_fig4h.sh`: Fig. 4h main-result plotting entry.
- `bash/plot_fig5c.sh`: Fig. 5c prevalence-peak/flow-volume plotting entry.
- `bash/plot_fig5_bde.sh`: Fig. 5b/d/e infection-curve plotting entry.
- `bash/run_all.sh`: toy simulation and plots, formal experiments, Fig. 4h,
  then Fig. 5.
- `graphs/graph1/average_graph_full_daily_preCovid_workday.pkl`: analysis-ready
  county-level mobility input.
- `output/`: output location for formal experiment arrays and flow summaries.
- `graphs/graph_start_end/artifacts/`: output location for main-result
  JPG/SVG/CSV products.

The mobility input is provided in the processed graph format read directly by
the experiment and plotting commands.

## Environment

From this directory:

```bash
conda env create -f environment.yml
conda activate epidemic_pynew
bash bash/verify_submission.sh
```

## Run sequence

Each stage can be launched through its Bash entry:

```bash
bash bash/run_toy_model.sh
bash bash/plot_toy_outputs.sh
bash bash/run_formal_experiments.sh
bash bash/plot_fig4h.sh
bash bash/plot_fig5c.sh
bash bash/plot_fig5_bde.sh
```

The equivalent all-in-one entry is:

```bash
bash bash/run_all.sh
```

All formal experiments can run on CPU, and the default uses eight CPU workers.
The PCH experiments involve large county-level matrix operations, for which
CUDA acceleration is recommended to reduce runtime. The worker or device
configuration can be adjusted for the available compute environment:

```bash
CURVE_POOLSIZE=4 MULTIPLE_POOLSIZE=4 bash bash/run_formal_experiments.sh
RUN_MULTIPLE=0 bash bash/run_formal_experiments.sh
US_REOPEN_USE_CUDA=1 CUDA_VISIBLE_DEVICES=0 bash bash/run_formal_experiments.sh
```

`RUN_MULTIPLE=0` runs the 21-point curve stage independently; the default
continues with the repeated runs used for the Fig. 5c distributions. The
toy-model entry uses the configured repeat and worker settings.

## Plotting outputs

The plot-ready formal arrays, per-run flow summaries, stored toy-model outputs,
and bundled Fig. 4h/Fig. 5 products are not included in the current Git
repository. They are provided in the Zenodo reproduction archive. Extract the
archive into the repository root so that its `output/`, `toyoutput/`, and
`graphs/graph_start_end/` contents use the paths expected by the plotting
scripts. See [ZENODO_ARCHIVE.md](ZENODO_ARCHIVE.md) for the archive layout.

The same output structure can also be generated by rerunning the formal and
toy-model experiments.

## Analysis inputs

The formal workflow reads the following analysis-ready inputs:

- the county-level pre-COVID workday mobility graph;
- county population density and age tables;
- the 2022 county case table used to initialize model metadata;
- the airport passenger seed table and CSA-to-county mapping;
- the fitted county transmission table and early-reopening index.

All input and output locations are expressed as repository-relative paths, and
the data layout matches the experiment and plotting entry points.

## Data sources

- County mobility inputs: Kang et al., *Multiscale dynamic human mobility flow
  dataset in the U.S. during the COVID-19 epidemic*, Scientific Data 7, 390
  (2020), via [GeoDS/COVID19USFlows](https://github.com/GeoDS/COVID19USFlows),
  based on mobility patterns provided by [SafeGraph](https://www.safegraph.com/).
- County COVID-19 case time series: processed from county-level records in
  [The New York Times repository](https://github.com/nytimes/covid-19-data)
  and the [Johns Hopkins University CSSE COVID-19 Data
  Repository](https://github.com/CSSEGISandData/COVID-19).
- County age structure, population and density: U.S. Census Bureau
  [American Community Survey table
  B01001](https://data.census.gov/) and the [Population Estimates
  Program](https://www.census.gov/programs-surveys/popest.html).
- Combined Statistical Area mapping: U.S. Census Bureau [metropolitan and
  micropolitan delineation
  files](https://www.census.gov/programs-surveys/metro-micro/about/delineation-files.html).
- Airport passenger data: U.S. Department of Transportation, Bureau of
  Transportation Statistics, [TranStats: T-100 International Market Data (All
  Carriers)](https://www.transtats.bts.gov/Fields.asp?gnoyr_VQ=FJD), accessed
  April 30, 2024.
- Airport code-to-county mapping: [iata-icao-UScounty](https://github.com/leakyH/iata-icao-UScounty),
  created by mapping publicly available airport coordinates to U.S. counties.
